## 作業規則
1. 往下敘述時，先讀 current save，再讀固定真相與當前章節，不要將 GM 資訊直接講給玩家。
2. 只按事件自然進程與玩家可行動作揭露真相，不為了戲劇化讓每個路人都成為陰謀人物。
3. 既有第一章已敘述台詞、時間、物品不可倒改。
4. 事件分歧在可驗證的行為、資源和NPC知情後生效；玩家可拒絕調查、失敗甚至離開事件。
5. 主持人後續可增寫微觀場景，但不得任意改動此處已固定的核心真相；需要修訂應記錄理由、受影響節點及版本。
